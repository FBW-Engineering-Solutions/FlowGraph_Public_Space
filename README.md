# FlowGraph Public Space

This repository is the **public discussion and issue-tracking space for FlowGraph**.

Visit the [official FlowGraph webpage](https://www.fbw-es.com/flowgraph/) to learn more about the project.

It is intended for the FlowGraph community to:

- Report bugs and unexpected behavior
- Request features and improvements
- Ask questions and discuss ideas
- Share feedback about the project
- Follow the status of reported issues and planned work

## What belongs here?

Please use this repository for public conversations about FlowGraph, including bug reports, feature requests, documentation feedback, and general project discussions.

Before opening a new issue or discussion, please search the existing topics to avoid duplicates. When reporting a bug, include enough detail to reproduce it, such as the FlowGraph version, environment, steps to reproduce, and any relevant logs or screenshots.

## What does not belong here?

This repository is not necessarily the source-code repository for FlowGraph. Code contributions should be made through the project repository and contribution process designated by the FlowGraph maintainers.

Please do not include sensitive information, private credentials, or security vulnerabilities in public issues. Follow the project’s security-reporting process for vulnerabilities.

## Community participation

Please keep discussions respectful, constructive, and focused on improving FlowGraph. Maintainers may label, organize, or close issues and discussions as needed to keep this space useful for the community.
